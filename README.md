Liver Patient Prediction

Project Overview

This project focuses on predicting liver disease using Machine Learning techniques and the Indian Liver Patient Dataset (ILPD).

The project analyses patient medical attributes and builds classification models to predict the presence of liver disease.

Dataset

- Dataset: Indian Liver Patient Dataset (ILPD)
- Total Records: 583
- Total Features: 10
- Target Variable: Liver Disease Prediction

Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Pickle

Machine Learning Algorithms

The following algorithms were implemented:

1. Logistic Regression
2. Decision Tree
3. Random Forest
4. K-Nearest Neighbors (KNN)
5. Support Vector Machine (SVM)
6. Gradient Boosting

Project Workflow

- Data Loading and Understanding
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Encoding and Scaling
- Model Training and Comparison
- Hyperparameter Tuning using GridSearchCV
- Model Evaluation
- Model Saving using Pickle

Model Performance

The original Random Forest model achieved:

- Accuracy: 75.44%
- Precision: 76.77%
- Recall: 93.83%
- F1-Score: 84.44%

Project Files

- "Liver_Patient_Prediction.ipynb" – Complete project notebook.
- "liver_patient_model.pkl" – Saved trained machine learning pipeline.

Conclusion

This project demonstrates how machine learning classification algorithms can be applied to patient medical data for liver disease prediction.

Note: This project is intended for educational purposes and is not a clinically validated diagnostic tool.
